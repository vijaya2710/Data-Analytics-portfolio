# COVID-19 India Data Analysis Dashboard

## Project Overview
This project analyzes COVID-19 data across Indian states using Power BI.

## Tools Used
- Power BI
- DAX
- Data Visualization

## Project Work
- Analyzed COVID-19 data.
- Created DAX measures.
- Built KPI cards to display important values.
- Created state-wise cases, deaths, and recoveries charts.
- Added map visualization.
- Added slicers and filters.
- Created a two-page interactive dashboard.

## Dashboard Features
- COVID-19 overview
- State-wise analysis
- Deaths and recoveries analysis
- Interactive filters and slicers
- Page navigation

## Project Outcome
Created an interactive Power BI dashboard to understand and compare COVID-19 data across Indian states.
